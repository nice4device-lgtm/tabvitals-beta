# TabVitals V0.4.5 Beta — Creator Test Kit

## What to test

1. Open the normal Chrome workload you use every day.
2. Check Chrome and system memory before the scan.
3. Run TabVitals X-Ray.
4. Look at the heaviest loaded tabs.
5. Sleep a few safe background tabs.
6. Check system memory again.
7. Return to a sleeping tab and confirm that it wakes normally.
8. Optionally test **Fix this site** on a website with a cache or session issue.

## What to record

- Operating system and installed RAM
- Number of open tabs
- Memory before and after
- Tabs slept
- Whether fan noise or heat changed
- Whether the result matched Chrome Task Manager or Activity Monitor
- Anything confusing, incorrect, or slower than expected

## Honest limitations

- Memory savings depend on the user’s actual Chrome session. TabVitals shows the recoverable amount on their own computer.
- Chrome does not expose every process in a way that can always be mapped one-to-one.
- There is no fixed amount of memory to promise.
- A sleeping tab may need to reload when reopened.
- Active, pinned, playing-audio, and Always Awake tabs are protected.
